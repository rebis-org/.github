# Support

## Scope and precedence

Organization-default support resources for all OSS and FOSS projects, as defined in [On Openness][openness] in the organization profile. Repository READMEs may add project-specific resources.

## Documentation

Each repository's README covers building, installing, and using its software, and points to any further documentation.

## Asking for help

- Technical questions and other public-record matters: organization [Discussions][discussions]. Search first; one matter per topic; state repository, version or commit SHA, platform, and toolchain, per the applicable contributing guide.
- Private matters: contact[at]rebis[dot]cn. State the affected repository and a minimal, non-sensitive summary; further details only on request.

## Expectations

Support is maintainer- and community-provided, best effort, as time permits; no service level, warranty, or dedicated channel is offered.

## Not handled here

- Suspected security vulnerabilities: the affected repository's private vulnerability reporting, per the applicable security policy.
- Conduct: the applicable code of conduct.

[discussions]: https://github.com/orgs/rebis-org/discussions
