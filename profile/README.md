## On the Name

### 鹽梅

> 若作和羹，爾惟鹽梅。[^1]

[^1]: 《說命》。

> 聲得鹽梅，響滑榆槿。[^2]

[^2]: 《文心雕龍》卷七《聲律》。

### Rebis

> Only when you make the two one, and in such a way that you make the man and the woman a single One in order that the man is not the man and the woman is not the woman, then you will go into the Kingdom.[^3]

[^3]: *Gos. Thom.* 22.

## 关于开放 / On Openness

本组织各该 public repositories 的开放属性由其许可证决定：以 [OSI 批准的许可证](https://opensource.org/licenses)或与之相容的许可证许可的 public repositories 是 OSS 项目，并根据各自 NOTICE、LICENSE 或 COPYING 授予相关权利；其中，同时符合 free 软件定义的 public repositories 是 FOSS 项目。不符合前述条件的 public repositories 是 source-available 项目。

前述 OSS 及 FOSS 项目，适用本 repository 的社区健康与治理文件：[`CODE_OF_CONDUCT.md`](../CODE_OF_CONDUCT.md)、[`CONTRIBUTING.md`](../CONTRIBUTING.md) 及 [`SECURITY.md`](../SECURITY.md)。如另有规定，从其规定。

Whether each public repository under this organization qualifies as open source is determined by its license. A public repository distributed under an [OSI-approved license](https://opensource.org/licenses), or a license compatible therewith, is an OSS project, with rights granted thereunder in accordance with its NOTICE, LICENSE, or COPYING, as applicable. A public repository that additionally meets the free software definition is a FOSS project. A public repository that does not meet the aforesaid criteria is a source-available project.

The aforementioned OSS and FOSS projects are subject to the community health and governance files provided in this repository: [`CODE_OF_CONDUCT.md`](../CODE_OF_CONDUCT.md), [`CONTRIBUTING.md`](../CONTRIBUTING.md), and [`SECURITY.md`](../SECURITY.md). Where any such public repository maintains its own community health and governance files, those files apply jointly with the said files; in the event of any inconsistency, the repository-specific provisions prevail.
